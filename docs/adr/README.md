| [0003](./0003-content-in-code-no-db.md) | Content in code, no database (Phase 2 deferral) | Accepted |
| [0004](./0004-mdx-blog-next-mdx-remote.md) | MDX blog via next-mdx-remote | Accepted |
| [0005](./0005-tailwind-v4-design-tokens.md) | Tailwind CSS v4 with theme tokens | Accepted |

Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) — Status, Context, Decision, Consequences.
